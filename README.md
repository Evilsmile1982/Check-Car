# car-check

Auto Check – Android App.

## Current first step
- Portrait Android home screen
- Garage/car visual
- Auto Check header animation: 2.5 seconds from top
- Three top buttons animate from the right over 2.5 seconds
- Three bottom buttons animate from the left over 2.5 seconds
- All six buttons are clickable
- Each button opens a temporary submenu screen
- GitHub Actions builds a debug APK automatically

## Build
GitHub Actions -> Build Android APK -> Run workflow.

The generated APK is uploaded as the workflow artifact `car-check-debug-apk`.
